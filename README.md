# Flash AI

Professional AI workspace built for chat, research, code, files and creative workflows.

## Run
npm install
npm run dev

## Environment
Add provider/API credentials only on the server side through Vercel environment variables. Never expose secrets in client code.

## Direction
- Multi-model AI routing
- Streaming chat
- Web research
- File and image understanding
- Image generation
- Code workspace
- Persistent history
- Secure server-side API routes
- Responsive premium UI
